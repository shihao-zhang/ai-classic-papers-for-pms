# 术语表

## CNN

Convolutional Neural Network，卷积神经网络。早期计算机视觉的核心架构，通过卷积核提取局部图像特征。

## Transformer

基于 self-attention 的模型架构。它让序列中不同位置可以直接交互，并且更适合大规模并行训练。

## Pre-training

预训练。先用大规模数据学习通用表示，再针对具体任务微调或提示。

## Fine-tuning

微调。在已有模型基础上，用特定任务或领域数据继续训练。

## Multimodal

多模态。模型同时处理图像、文本、音频、视频等多种输入或输出。

## Diffusion Model

扩散模型。通过逐步加噪和去噪学习生成数据的模型家族。

## Contrastive Learning

对比学习。通过拉近正样本、推远负样本来学习表示。

## Reinforcement Learning

强化学习。智能体通过与环境交互、获得奖励信号来学习策略。
