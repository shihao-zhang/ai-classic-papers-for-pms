# NotebookLM Slides 提示词

用于把每个分类的论文笔记生成一份系列化综述 slide deck。使用时，把同一分类下的 Markdown 笔记作为 NotebookLM sources，再把下面提示词粘贴到 NotebookLM 的 slide deck 自定义提示词中。

## 通用提示词

```text
请基于我提供的这一组论文笔记，生成一份中文 detailed slide deck，面向 AI 产品经理和技术创作者。

不要逐篇摘要。请找出一条“技术演进与能力边界改写”的主线：用一个真实的产品问题开场，以故事化叙事展开每个关键阶段的瓶颈、代表论文的核心机制和能力跃迁。关键论文要讲清它解决了什么、怎么做的、打开了什么新空间、仍受哪些约束；关键论文页标题必须显式包含论文/模型名，推荐“论文/模型名（年份）：能力边界变化”，合并页需在标题或副标题列出代表论文名；其余论文可并入对比页。必要时用流程图、对比矩阵或能力地图辅助理解。

结尾不要做技术选型指南，而要沉淀判断力：这些论文如何改变我们评估技术的方式，哪些约束至今有效，面对新模型和新论文时如何提问、验证和避坑。

根据论文数量，自然融入以下形态：问题引入、技术演进时间线、关键机制拆解、范式对比、能力边界地图、常见误区、PM 追问清单、复盘检查题（附简短答案）。章节间注意回到产品视角。必要推断请标注“基于材料的推断”。

页数根据论文数量自适应，不要压缩成 executive summary。每个关键阶段至少 1 页；同范式多篇论文可合并为对比页。讲清主线为准，不凑页数。

设计：稳定复用“白底轻蓝图”视觉：16:9 横版，白色或极浅冷灰背景，深蓝灰正文，钢蓝/浅蓝少量强调。蓝图元素只作低透明度点缀；核心图示优先用扁平二维框架图（方块、箭头、模块、矩阵、网络连接、状态转移），避免整页方格纸、厚边框/阴影、大色块、巨大勾叉、三维机械元素和营销/卡通主视觉。每页只突出一个判断，页面文字用短句承载结论，长解释放入 speaker notes（含过渡句和关键判断）。
```

## 方法论

NotebookLM 生成 slides 的稳定性主要来自输入材料，而不是更长的提示词。建议按“来源 -> 叙事 -> 页面 -> 视觉”的顺序控制：

- 来源：每次只放入一个分类的论文笔记，必要时额外放一份简短 deck brief，说明论文清单、推荐主线、关键误区和不要误读的边界。
- 叙事：先确定“问题 -> 瓶颈 -> 机制 -> 能力边界 -> PM 判断力”的讲述路径，再让 NotebookLM 组织页面。
- 页面：每页只突出一个判断，标题写观点，复杂解释放到 speaker notes。
- 视觉：只给稳定风格和禁区，避免把提示词写成过细的设计规范，给模型保留泛化空间。

## 使用建议

- 每次只放入一个分类的论文笔记，例如 CV 10 篇或 NLP 7 篇。
- 不要额外指定固定页数，让 NotebookLM 根据论文数量和范式跨度决定信息密度。
- 建议为每个分类准备一份简短 deck brief 作为 source，而不是继续加长主提示词。
- 如果生成结果过像 executive summary，追加要求“展开关键机制页和章节复盘页”。
- 如果关键论文名只出现在正文而没有进入标题，属于结构问题，应调整主提示词或 deck brief 后重新生成。
- 如果视觉偏练习册、机械蓝图或大色块，追加要求“减少勾叉、厚边框、满屏网格和三维机械元素；用白底轻蓝图、二维框架图和轻量信息卡表达”。
- 如果生成结果存在事实或论文机制错误，应调整 sources / deck brief 后重新生成；逐页 Revise 更适合修正视觉、措辞和布局焦点。
