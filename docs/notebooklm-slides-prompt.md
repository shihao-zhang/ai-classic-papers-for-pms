# NotebookLM Slides 提示词

用于把每个分类的论文笔记生成一份系列化综述 slide deck。使用时，把同一分类下的 GitHub Markdown 笔记作为 NotebookLM sources，再把下面提示词粘贴到 NotebookLM 的 slide deck 自定义提示词中。

## 通用提示词

```text
请基于我提供的这一组论文笔记，生成一份中文 detailed slide deck，面向 AI 产品经理和技术创作者。

不要逐篇摘要。请找出一条“技术演进与能力边界改写”的主线：用一个真实的产品问题开场，以故事化叙事展开每个关键阶段的瓶颈、代表论文的核心机制和能力跃迁。关键论文要讲清它解决了什么、怎么做的、打开了什么新空间、仍受哪些约束；其余论文可并入对比页。必要时用流程图、对比矩阵或能力地图辅助理解。

结尾不要做技术选型指南，而要沉淀判断力：这些论文如何改变我们评估技术的方式，哪些约束至今有效，面对新模型和新论文时如何提问、验证和避坑。

根据论文数量，自然融入以下形态：问题引入、技术演进时间线、关键机制拆解、范式对比、能力边界地图、常见误区、PM 追问清单、复盘检查题（附简短答案）。章节间注意回到产品视角。必要推断请标注“基于材料的推断”。

页数根据论文数量自适应，不要压缩成 executive summary。每个关键阶段至少 1 页；同范式多篇论文可合并为对比页。讲清主线为准，不凑页数。

设计：稳定复用“白底技术蓝图”视觉：16:9 横版，白色或极浅冷灰背景，深蓝灰正文，钢蓝/浅蓝作少量强调，细线网格、等距线稿或流程图作技术示意。版面清爽留白，避免大面积色块、米黄色/绿色卡片底、厚重圆角卡片、强渐变、卡通插画、营销风主视觉，以及与机制无关的散点/曲线图。每页标题带观点或问题，正文 3-5 要点，配 speaker notes（含过渡句和关键判断）。
```

## 使用建议

- 每次只放入一个分类的论文笔记，例如 CV 10 篇或 NLP 7 篇。
- 不要额外指定固定页数，让 NotebookLM 根据论文数量和范式跨度决定信息密度。
- 如果生成结果过像 executive summary，追加要求“展开关键机制页和章节复盘页”。
- 如果视觉偏成营销卡片或大色块，追加要求“白底技术蓝图风，细线蓝图/流程示意，避免大卡片与抽象营销图”。
