# Word2Vec：Efficient Estimation of Word Representations in Vector Space

> 分类：序列建模前史  
> 年份：2013  
> 论文：https://arxiv.org/abs/1301.3781  
> 状态：draft

## 一句话

Word2Vec 用一个极简、能在十亿级语料上快速训练的浅层模型，把每个词学成一个低维稠密向量，让“词义相近”第一次变成“向量距离相近”这种可计算的几何关系；它把 embedding 确立为 NLP 的标准输入，也让“用海量无标注文本自监督地学表示”成为后来预训练范式的雏形。

## 背景问题

在 Word2Vec 之前，词在多数 NLP 系统里是用 one-hot 表示的：词表有多大，向量就有多长，只有对应位置是 1，其余全 0。这种表示有两个致命问题。第一，维度极高且稀疏。第二，也是更要命的，任意两个词的向量都互相正交——“猫”和“狗”之间的相似度，跟“猫”和“法律”之间的相似度，在数学上完全一样，都是零。模型从这种表示里读不出任何语义关系。

当时已经有人尝试学“分布式表示”，也就是把词压成低维稠密向量。Bengio 在 2003 年的神经语言模型（NNLM）就证明了：神经网络可以一边训练语言模型，一边把词向量当副产品学出来，而且这些向量能反映语义。LSA、LDA 这类基于矩阵分解或主题模型的方法也能给词一些向量表示。

卡点不在“能不能学”，而在“能不能又好又便宜地学到足够大的规模”。NNLM 这类模型有一个昂贵的非线性隐藏层，再加上要对整个词表做 softmax，计算量很大，很难在真正海量的语料（几十亿词）上训练。结果就是：分布式词向量的潜力大家都看到了，但没有一个又快又能扩展的方法，把它做成人人可用的基础设施。

Word2Vec 的问题意识非常工程化：能不能把模型砍到极简，去掉昂贵的部分，专门优化“学词向量”这一件事，从而在超大语料上快到可以让整个行业都用得起？

## 核心方法

Word2Vec 背后是一个很老的语言学直觉——**分布式假设**（distributional hypothesis）：一个词的意义，藏在它经常和哪些词一起出现里（you shall know a word by the company it keeps）。“咖啡”和“茶”意思相近，是因为它们出现的上下文高度重叠（喝、热、杯、提神）。Word2Vec 做的，就是把这个直觉变成一个能在海量文本上跑的预测任务。

### 1. 两种架构：CBOW 与 Skip-gram

论文提出两个互为镜像的模型。

- **CBOW**（Continuous Bag-of-Words，连续词袋）：拿一个词周围的上下文（比如前后各两个词）去预测中间这个词。相当于做完形填空：“我每天早上喝一杯 ___”，让模型猜中间是什么。
- **Skip-gram**：反过来，拿中间这个词去预测它周围的上下文词。给“咖啡”，让模型猜它周围可能出现“喝”“早上”“提神”。

两者训练时都不关心“猜得准不准”这个任务本身——真正想要的是训练过程中顺带学到的那一层词向量。一个词反复出现在相似的上下文里，它的向量就会被推到相似的位置。Skip-gram 在罕见词上通常表现更好，CBOW 训练更快，这是一个常见取舍。

### 2. 关键动作：把昂贵的部分砍掉

Word2Vec 真正的“聪明”不在于发明了全新机制，而在于**做减法**。它把 NNLM 里那个昂贵的非线性隐藏层直接去掉，模型退化成一个非常浅的结构：输入词向量，做一次简单的线性组合，直接预测。

这一刀下去，模型的表达能力变弱了，但换来了巨大的训练速度。正因为快，它才能吃下几十亿词的语料；而对学词向量来说，**“在更多数据上跑更简单的模型”往往胜过“在更少数据上跑更复杂的模型”**。这是整篇论文最值得产品经理记住的取舍。

### 3. 让训练真正跑得动的加速技巧

即便砍掉了隐藏层，对几十万词的词表做 softmax 仍然很贵。论文及其紧随其后的姊妹论文给出了两条加速路径：

- **Hierarchical softmax**（层级 softmax）：把词表组织成一棵树，预测一个词变成走一条从根到叶的路径，计算量从“和词表一样大”降到“词表大小的对数”。
- **Negative sampling**（负采样）：每次不更新整个词表，只更新正确答案和少量随机抽到的“错误词”。这个技巧出自同年稍后的姊妹论文（*Distributed Representations of Words and Phrases*），不是本篇 1301.3781 的内容，但它和 Word2Vec 几乎是绑在一起被记住的。

需要澄清归因：本篇论文的核心贡献是 **CBOW / Skip-gram 这两个高效架构**和对训练效率的极致优化；negative sampling、高频词下采样等是姊妹论文的补充。

### 4. 著名现象：向量里浮现出的语义与语法

Word2Vec 让人印象最深的，是它学出的向量空间里出现了**线性的语义关系**。最有名的例子是向量算术：`vector("king") - vector("man") + vector("woman")` 得到的向量，最接近 `vector("queen")`。类似地，“巴黎之于法国，如同东京之于日本”这种类比关系，也能用向量加减近似还原。

这说明模型没有被告诉任何语法或语义规则，却从纯粹的“谁和谁一起出现”里，自己把“性别”“首都-国家”“单复数”“时态”这些维度大致组织进了向量空间的几何结构里。论文专门设计了一个语义-语法类比测试集来量化这种能力。

## 为什么经典

第一，它把“词义”变成了可计算的几何对象。在 Word2Vec 之后，“两个词有多像”可以直接用向量余弦相似度算出来，语义检索、聚类、近义词扩展这些以前很难的事，一下子有了统一的数学工具。

第二，它让 embedding 成为 NLP 的标准输入层。此后很长一段时间，几乎所有 NLP 模型的第一层都是“把词查成预训练好的向量”，再往上接具体任务。预训练词向量成了几乎免费的、可复用的基础设施。

第三，它示范了一条后来被反复验证的路线：**简单架构 + 海量数据 + 自监督信号**。Word2Vec 不需要任何人工标注，监督信号完全来自文本自身（“这个上下文里中间该是什么词”）。这正是后来 ELMo、BERT、GPT 乃至所有大模型预训练的核心思路的早期雏形——虽然那些模型的具体机制和 Word2Vec 已经很不一样。

第四，它把研究成果做成了人人可用的工具。开源的 word2vec 训练又快又稳，让学术界和工业界都能在自己的语料上训出词向量，极大加速了整个领域的扩散。

## 产品经理启发

1. **embedding 是“把非结构化语义变成可计算向量”的底层能力。** 今天的语义搜索、推荐召回、内容去重、聚类分桶、RAG 检索，本质都建立在“把对象变成向量、用距离衡量相关性”这件事上。Word2Vec 是这条产品能力线的源头，理解它就理解了向量数据库和 embedding API 为什么有用。

2. **自监督意味着无标注数据也能产生价值。** Word2Vec 不需要一条人工标注，光靠原始文本就学出了有用的表示。做数据策略时，别只盯着昂贵的标注数据，要先问：手里的海量原始日志、文档、行为序列，能不能用自监督的方式榨出表示。

3. **学会区分“内在评估”和“外在评估”。** 词类比测试（king-queen）很漂亮，是内在评估；但它不直接等于下游任务（搜索、分类）变好。产品里评估一个 embedding 方案，最终要看它在真实业务指标上的外在表现，别被一个好看的内在 demo 带跑。

4. **模型会原样继承数据里的偏见，这是产品风险。** Word2Vec 会从语料里学出“man 之于 computer programmer，如同 woman 之于 homemaker”这类带社会偏见的关联。任何用 embedding 做匹配、推荐、筛选的产品，都可能把这些偏见放大成歧视性结果，需要在选型和上线阶段就做评估与治理。

5. **“一个词一个固定向量”是有边界的能力。** Word2Vec 给每个词唯一一个向量，无法区分“苹果手机”和“吃苹果”里的两个“苹果”。当产品需要消歧、需要上下文相关的理解时，静态词向量不够用，要换上下文相关的表示（这是后来 ELMo/BERT 才解决的，不是 Word2Vec 的能力）。选型时先想清楚任务到底需不需要上下文。

## 局限与争议

第一，静态词向量无法消歧。每个词只有一个向量，多义词被强行压成一个点。“bank”在“river bank”和“bank account”里共用同一个向量，模型分不清。上下文相关的词表示是后来 ELMo、BERT 等工作的贡献，**不能把这个能力回算到 Word2Vec 头上**。

第二，它不建模词序和句子结构。CBOW 的名字里就有“bag”（词袋）——上下文是被当成一袋无序的词处理的。Word2Vec 学的是词级别的表示，不直接给出句子或段落的表示，更不理解语法结构。

第三，未登录词（OOV）问题。词表外的词没有向量，新词、拼写变体、罕见专名都无法表示。后来 FastText 用子词（subword）信息缓解了这一点。

第四，它不是 attention 的起源。Word2Vec 和注意力机制没有关系，attention 是 Seq2Seq 之后（Bahdanau 2014）才出现的思路。把 attention 或上下文建模归给 Word2Vec 是常见的张冠李戴。

第五，评估方式有争议。词类比任务到底在多大程度上反映“理解”，学界一直有讨论；有些类比关系可能是数据集构造和向量空间几何的巧合，而非模型真正掌握了概念。

## 今天怎么看

今天没有人会用静态词向量去做最前沿的 NLP 任务了——大模型里的 token embedding 是上下文相关的，能力远超 Word2Vec。但 Word2Vec 埋下的思想反而比当年更主流：把万物变成向量、用相似度做检索和匹配，正是向量数据库、语义搜索、RAG 的核心范式。读 Word2Vec 的价值不在记住 CBOW 和 Skip-gram 的细节，而在理解“分布式表示 + 自监督 + 几何即语义”这套底层世界观。

仍然重要的部分：

- embedding 作为“把对象映射到向量空间”的通用接口；
- “语义相近 = 向量相近”这条几何直觉，支撑着今天所有的向量检索；
- 用海量无标注数据自监督地学表示，是预训练范式的早期雏形；
- 简单模型 + 更多数据常常胜过复杂模型 + 更少数据，这条工程取舍至今成立。

已经被后续工作改造或替代的部分：

- 静态词向量被上下文相关表示（ELMo → BERT → 大模型的 token embedding）全面取代；
- OOV 问题被子词切分（FastText、BPE、WordPiece）解决；
- 词级别表示被句子、段落、文档级别的 embedding 扩展；
- 当年昂贵的“训练词向量”如今变成调一次 embedding API 就能拿到的现成能力。
