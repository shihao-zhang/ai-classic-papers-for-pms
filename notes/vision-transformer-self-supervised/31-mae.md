# MAE：Masked Autoencoders Are Scalable Vision Learners

> 分类：视觉 Transformer 与自监督  
> 年份：2021  
> 论文：https://arxiv.org/abs/2111.06377  
> 状态：reviewed

## 一句话

MAE 把“遮住大部分图像 patch、再让模型重建缺失内容”做成了一条简单又高效的视觉自监督预训练路线：它建立在 [ViT](30-vit.md) 的 patch 化之上，靠**高比例遮挡 + 不对称 encoder-decoder + 像素重建**，让 ViT 能像语言模型用 BERT 那样，从海量无标注图像里学到可迁移的视觉表示，而不必依赖大规模人工标注。

## 背景问题

NLP 那边的 BERT 已经证明了一条好用的自监督路线：遮住一部分 token 再让模型预测，就能学到强语义表示，不需要标注。视觉自然会想照搬——可惜直接搬过来并不顺手。

第一个障碍是**信息冗余**。语言里每个 token 都携带不少信息，遮掉 15% 就足够难。但图像像素高度冗余：相邻 patch 长得很像，遮掉一小块，模型常常靠周围 patch 直接“插值”补回来，根本不用理解物体是什么。任务太容易，学到的就只是低层纹理，而不是高级语义。

第二个障碍是**成本**。视觉标注很贵——ImageNet 这类监督数据推动了 AlexNet、ResNet、ViT，但更大规模的图像（业务图库、视频帧、工业/医学影像）几乎都没有标注。如何把这些无标注数据变成视觉基础模型的燃料，是绕不开的问题。

所以 MAE 的问题意识可以浓缩成一句：**怎样设计一个简单、可扩展、又特别适配 ViT 的自监督任务，让模型从未标注图像里学到能迁移到下游的表示，同时训练还得划算？**

## 核心方法

MAE 的核心是 masked autoencoding：把图像切成 patch（这一步直接复用 ViT），随机遮掉一大半，让模型重建被遮的部分。朴素到几乎没有花哨组件，但每个设计选择背后都是一笔明确的账。

### 1. 高 mask ratio（≈75%）：用“遮得狠”把任务变难

MAE 随机遮住约 75% 的 patch，只留下约四分之一可见。这个比例远高于 BERT 的 15%——不是随手调的超参，而是针对“图像比文本冗余得多”的直接回应。

人话讲：遮 15%，相当于一张脸只挡住一只眼睛，靠对称和周围像素就能猜出来，模型学的是“局部补全”；遮 75%，相当于只露出零散几块，模型必须先在脑子里建立“这大概是一张脸、鼻子嘴在哪、整体什么姿态”，才能把缺失部分填回去。只有把任务逼到“不理解整体就做不出来”，模型才被迫学到形状、结构、上下文这些高级语义。

取舍：mask ratio 是个需要拿捏的旋钮。太低，模型偷懒学纹理插值，表示弱；太高到极端，可见信息不足以支撑合理重建，反而学不到东西。75% 是论文找到的甜区，且这个甜区明显高于直觉，本身就是 MAE 的关键发现之一。

### 2. encoder 只看可见 patch：把“难度”和“省钱”合成一件事

MAE 的 encoder（一个标准 ViT）**只处理那约 25% 的可见 patch**，被遮的 patch 根本不进 encoder。

人话讲：既然大部分 patch 都被遮了，为什么还要花算力让 encoder 去“看”那些占位的空格？干脆让重活的 encoder 只处理真实信息，序列长度直接砍到原来的四分之一左右。Transformer 的注意力成本对序列长度大致是平方关系，序列短一截，单步训练就便宜一大截。

取舍/妙处：这是 MAE 最优雅的地方——**高 mask ratio 同时干了两件事**。它既把自监督任务变难（逼出语义，见上一节），又把 encoder 的计算量大幅压低（这一节）。难度和成本本是矛盾，这里却被同一个设计一起改善，这也是 MAE“能 scale”的工程根源。

### 3. 不对称的轻量 decoder：重建是手段，encoder 才是目的

被遮的 patch 由一个**独立、更轻的 decoder** 负责。decoder 拿到 encoder 输出的可见 patch 表示，再补上代表缺口的 mask token（按位置插回去），去预测被遮 patch 的内容。这个 decoder 通常比 encoder 窄、浅得多。

人话讲：MAE 是“非对称”的——encoder 重、decoder 轻，两边干的活不一样。原因在于二者目标不同：encoder 要学的是能迁移、能复用的好表示，所以要厚实；decoder 只是预训练期间用来“把缺口填上”的临时脚手架，预训练一结束就基本扔掉。**下游任务（分类、检测、分割）只取 encoder，不要 decoder。**

取舍：故意让 decoder 轻，是要把建模能力压在 encoder 上——decoder 太强会独揽重建、让 encoder 偷懒。轻 decoder 还顺带再省一笔训练成本。代价是重建图通常糊，但这无所谓，目标从来不是好看的图。

### 4. 像素重建目标：低级的题，逼出高级的解

MAE 的训练目标朴素到有点反直觉：直接预测被遮 patch 的**原始像素**，用均方误差（MSE）衡量重建好坏。没有对比学习、没有负样本队列、没有精心设计的数据增强、没有离散 token 词表。

人话讲：题目本身（“把这些像素填回去”）确实低级，但因为遮得太狠，要把它做对，模型绕不开对整体语义的理解。换句话说，MAE 用一个低级目标当“逼供工具”，逼 encoder 交出高级表示。

取舍与红线：必须分清两件事——**MAE 重建 patch 是为了训练出好的 encoder 表示，不是为了生成高质量图像**。它和 diffusion / 文生图是两码事：diffusion 的产物就是图，MAE 的产物是 encoder，重建图只是副产品且往往很糊。把 MAE 当成“图像生成模型”是典型误读。另一点：像素 MSE 这个目标偏低层，最终学到的表示到底够不够语义，不能靠重建好看与否判断，**只能靠下游任务的迁移效果来验证**。

## 为什么经典

第一，它让 ViT 的自监督预训练变得**简单又强**。在 MAE 之前，主流视觉自监督多走对比学习路线，要维护负样本、大 batch、动量编码器、复杂增强等一堆机制。MAE 证明：只要任务难度对了，朴素的遮挡-重建就能学到强表示，机制复杂度大幅下降。

第二，它把视觉学习真正拉进了 **scaling 叙事**。MAE 与 ViT 天然契合，模型越大、数据越多越能继续受益，且因为 encoder 只看可见 patch，训练成本相对可控。这让视觉基础模型更接近 NLP 大模型“预训练 + 迁移”的逻辑。

第三，它降低了**标注依赖**。对手里有海量无标注图像、却缺标注的团队，MAE 给出了一条把这些数据变成预训练底座的现实路径，再迁移到分类、检测、分割等下游任务。

第四，它把“一个好设计可以同时优化多个维度”示范得很干净。高 mask ratio 同时提难度、降成本，这种“一箭双雕”的结构选择，成了后续很多高效自监督工作的参照。

需要划清的归因边界：MAE 属于 masked image modeling 这一支，和**对比学习路线（DINO、MoCo 等）**、**图文弱监督路线（[CLIP](../multimodal/18-clip.md)）**、**离散 token 重建路线（BEiT）** 是不同方法，各有各的贡献，不能混为一谈、更不能都算到 MAE 头上。

## 产品经理启发

1. **无标注数据本身就是资产，别只盯着标注样本。** 很多业务手握海量图片、视频帧、工业图、医学影像，却因为没标注而当成“沉睡数据”。MAE 提醒：这些原始数据可以先喂自监督预训练，把“没标注”从负担变成底座，标注预算则集中花在真正需要的下游微调上。

2. **任务难度要刻意设计到“刚刚好难”。** 遮太少，模型只学局部纹理；遮够多，才被逼着理解整体。这个道理可以平移到产品评测：太容易的 benchmark 会系统性高估模型能力，让你误判上线水位。设计训练任务和评测集时，都要主动问“这道题逼模型学真本事了吗”。

3. **优先押注“同一设计同时提难度又降成本”的好结构。** MAE 的高 mask ratio 既让任务更难、又让 encoder 算力更省——难度和成本本该是矛盾，却被一个设计一起改善。PM 在技术选型时要识别并偏爱这类“一箭双雕”的方案，它们的 ROI 通常远好于单点优化。

4. **预训练和下游业务要分层规划，预训练≠解决业务。** MAE 学到的是通用视觉表示，不是某个业务的答案。落地时仍要在 encoder 之上做下游标注、任务头训练、评估和适配（分类/检测/分割各不相同）。排期上要把“预训练底座”和“下游适配”当成两条相互衔接但独立的工作流，别指望预训练一步到位。

5. **缺标注但富数据时，先自监督再少量监督，往往比从零训练更划算。** 当原始数据充足、标注稀缺，“自监督预训练 + 小样本监督微调”的组合通常比直接监督从零训练更省钱、更稳、上限更高。这是 MAE 给 PM 的核心数据策略，而不仅是一个模型。

6. **重建好不好看不是验收标准，下游指标才是。** MAE 重建的图往往糊，但这恰恰说明：不要用“生成结果像不像”来评判一个表示学习方案。验收自监督底座，要看它迁移到你真实任务上的提升，而不是看中间产物的观感。

## 局限与争议

第一（原论文边界）：MAE 的重建目标服务于**表示学习，不等于图像生成**。它重建 patch 是为了训练 encoder，重建图通常很糊；把它和 diffusion、文生图相提并论是误读——这是 MAE 主动选择的定位，不是缺陷。

第二（原论文边界）：MAE 对 **ViT 架构特别友好**，因为“只编码可见 patch”依赖 token 化、序列可裁剪这些 ViT 特性。它不保证在所有骨干、所有任务上都最优，原论文也没有声称要替代其他自监督路线。

第三（原论文边界）：像素 MSE 是个偏低层的目标，**学到的表示是否足够语义无法直接判断，必须靠下游迁移验证**。论文给的是经验性结论，不是“一定学到语义”的保证。

第四（后续工作扩展）：把目标从“原始像素”换成更高层的预测目标，是后续的活儿。BEiT 走的是**预测离散视觉 token**，MaskFeat 等走的是**预测特征（如 HOG / 深层特征）**，试图让自监督信号更偏语义——这些是别人的贡献，不应算到 MAE 头上。

第五（后续工作扩展）：把 masked modeling 扩到**视频、多模态、音频**（如 VideoMAE、各类多模态 MAE 变体）也是后续工作。MAE 原文聚焦静态图像，跨模态扩展是社区在其思路上的延伸，归因要分清。

第六（共性风险）：自监督并不天然中立。**无标注数据如果偏向某些场景、设备、地域或人群，学到的表示就会带偏**，而且因为没有标注做对照，这种偏差更隐蔽、更难发现。数据出身仍是产品风险的一部分。

## 今天怎么看

MAE 是视觉自监督学习的重要里程碑。它不是唯一方案，但用近乎极简的设计证明了 “ViT + masked modeling” 的规模化潜力，并把一条“朴素也能强”的路线钉进了视觉预训练的工具箱。

仍然重要的部分：

- “遮挡 - 重建 - 预测缺失信息”作为一种通用、可迁移的自监督思路；
- 高 mask ratio 同时把任务变难、把 encoder 变省的“一箭双雕”设计哲学；
- 不对称 encoder-decoder——重 encoder 学表示、轻 decoder 当临时脚手架的分工；
- “缺标注、富数据时先自监督预训练再少量监督适配”这条 PM 级数据策略。

已经被后续工作改造或替代的部分：

- 像素重建目标被 BEiT（离散 token）、MaskFeat（特征预测）等更偏语义的目标改造；
- 单图像范围被 VideoMAE、多模态 MAE 等扩展到视频与跨模态；
- 在某些场景，对比学习（DINO 系）、图文弱监督（CLIP）仍是有竞争力甚至更合适的替代路线，没有被 MAE 取代；
- 下游用法上，纯靠 encoder 表示迁移，正与 CLIP 式语义对齐、指令/多模态对接等方式并存互补。

读 MAE 的价值，不在记住“75%”这个数字，而在理解一个判断：当任务难度被设计对、且这个难度恰好顺手把成本也压下去时，最朴素的自监督也能 scale。对 PM 来说，它提供的是一个数据视角——把无标注数据当资产，把预训练和下游分层规划，往往比从零硬训更现实。

## 理解检查

1. MAE 为什么用约 75% 这么高的 mask ratio，而 BERT 只遮 15%？遮太低和遮太高分别会怎样？

<details>

- 图像像素冗余远高于文本，遮太少模型靠周围 patch 插值就能补，只学到局部纹理。
- 遮到 75% 才逼模型理解整体结构、形状、上下文，学到高级语义。
- 太低：任务太易、表示弱；太高到极端：可见信息不足、无法合理重建。75% 是甜区，且明显高于直觉，本身是关键发现。

</details>

2. 为什么 MAE 的 encoder 只处理可见 patch？这一个设计同时带来了哪两个好处？

<details>
<summary>参考要点（先自己答，再展开）</summary>

- 被遮的 patch 不进 encoder，序列长度砍到约四分之一。
- 好处一：高 mask ratio 让自监督任务更难，逼出语义表示。
- 好处二：注意力成本随序列长度大致平方，序列变短让训练大幅省算力。
- 关键在于“难度”和“成本”被同一个设计一起改善，这是 MAE 能 scale 的根源。

</details>

3. MAE 为什么用“轻量、非对称”的 decoder？下游任务到底用 encoder 还是 decoder？

<details>
<summary>参考要点（先自己答，再展开）</summary>

- encoder 要学可迁移的好表示，所以厚；decoder 只是预训练期填缺口的临时脚手架，所以轻。
- 下游任务（分类/检测/分割）只取 encoder 表示，decoder 基本丢弃。
- decoder 故意做轻，避免它独揽重建、让 encoder 偷懒；顺带再省算力。代价是重建图糊，但无所谓。

</details>

4. 为什么 MAE 重建图像不等于做文生图或扩散生成？这条归因边界为什么重要？

<details>
<summary>参考要点（先自己答，再展开）</summary>

- MAE 重建 patch 的目的是训练出好的 encoder 表示，重建图只是副产品，往往很糊。
- diffusion / 文生图的产物本身就是图像，目标和 MAE 完全不同。
- 把 MAE 当“图像生成模型”是典型误读；它的价值在表示，不在生成质量。

</details>

5. 某业务有海量无标注图像、标注预算有限，为什么“先自监督预训练再少量监督微调”常比从零监督训练更划算？落地上还要补什么？

<details>
<summary>参考要点（先自己答，再展开）</summary>

- 自监督把海量无标注数据变成预训练底座，标注预算集中花在下游微调，整体更省、更稳、上限更高。
- 从零监督训练只能用有限标注，数据利用率低，ViT 这类模型还吃数据。
- 落地还要补：下游标注、任务头训练、按分类/检测/分割分别适配与评估，预训练≠直接解决业务。
- 同时留意无标注数据的分布偏差会被表示继承，且因无标注对照更隐蔽。

</details>
