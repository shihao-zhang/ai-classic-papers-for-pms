# ResNet：Deep Residual Learning for Image Recognition

> 分类：计算机视觉  
> 年份：2015  
> 论文：https://arxiv.org/abs/1512.03385  
> 状态：reviewed

## 一句话

ResNet 把“更深的神经网络难训练”改写成“让每一小段网络只学习相对输入的改变量”，用残差连接（residual connection / skip connection）让 100 层以上的视觉网络真正变得可训练，并推动 `x + F(x)` 成为后续深度模型里的通用结构语言之一。

## 背景问题

在 ResNet 之前，计算机视觉已经从 AlexNet、VGGNet、GoogLeNet/Inception 看到一个强信号：网络越深，越可能学到从边缘、纹理、局部形状到语义对象的多层特征。问题是，“继续堆层数”并不自动带来更好效果。

早期大家担心的是梯度消失/爆炸（vanishing/exploding gradients）：模型太深时，反向传播的信号传不到前面的层，训练从一开始就不收敛。到 2015 年前后，较好的初始化、Batch Normalization 等方法已经缓解了这个问题，让几十层网络可以开始训练。

但 ResNet 指出的更棘手问题是 degradation problem：当普通网络（plain network）继续变深时，训练误差反而变高，测试误差也变高。它不是典型过拟合，因为过拟合通常表现为训练集更好、测试集更差；这里是更深模型连训练集都拟合得更差。

这件事违反直觉。理论上，一个更深的网络至少可以“模拟”浅网络：新增的层什么都不做，只做 identity mapping，把输入原样传过去。那么更深模型的训练误差不应该比浅模型高。现实却是优化器很难在普通堆叠层里自动学出这种“什么都不做”的路径。

对产品经理来说，这个背景问题可以翻译成一句话：能力模块变多，不代表系统能力自然变强；如果模块之间没有好的信息通路和默认行为，复杂度会先伤害可训练性、稳定性和交付效率。

## 核心方法

ResNet 的核心不是发明了“绕过层的连接”这个想法，而是把它变成了一个简单、可规模化、可验证的深度网络设计原则：不要让一组层直接学习目标映射 `H(x)`，而是让它学习残差 `F(x) = H(x) - x`，最后输出变成：

```text
输出 = F(x) + x
```

这里的 `x` 是输入，`F(x)` 是若干卷积层学到的改变量。直观理解是：

- 普通网络问每一组层：“请你从零开始生成一个新表示。”
- ResNet 问每一组层：“先保留原来的表示，你只负责补充、修正或变换其中需要改变的部分。”

这个设计有几个关键点。

第一，identity shortcut 给信息提供了一条直达通道。即使 `F(x)` 一开始学得不好，`x` 仍然可以直接传到后面。模型的默认行为从“每层都必须做对”变成“做不好时至少可以接近不破坏输入”。

第二，它改善了梯度流（gradient flow）。反向传播时，梯度不必完全穿过每一层的非线性变换才能回到前面；加法路径提供了更短、更直接的信号通路。用非公式的话说，训练信号有了“主路”，各层学习的是在主路上加多少修正，而不是每一站都重新造路。

第三，它让深层网络更容易学习 identity mapping。普通网络如果想让新增层“不改变输入”，需要多层权重和非线性组合刚好实现接近恒等映射；残差块里只要让 `F(x)` 接近 0，整体就接近 `x`。这就是 ResNet 对 degradation problem 的关键回应。

第四，残差块几乎不增加参数和计算量。原论文强调 identity shortcut 本身没有额外参数，只有当输入和输出维度不一致时，才用投影（projection shortcut，例如 1x1 convolution）对齐维度。这使得实验比较更有说服力：同样深度、宽度、计算量附近，残差结构比普通堆叠更容易优化。

典型 ResNet block 可以理解为：

1. 输入 `x` 进入若干卷积层，得到残差分支 `F(x)`。
2. 输入 `x` 同时通过 shortcut 保留下来。
3. 两条路径做 element-wise addition，得到 `F(x) + x`。
4. 后续再经过激活函数，进入下一个 block。

原论文在 ImageNet 上训练了 18、34、50、101、152 层等版本，也在 CIFAR-10 上分析了 110 层和 1202 层等极深网络。最有代表性的结论不是“152 层这个数字很神奇”，而是残差学习让“深度”从危险变量变成可利用变量。

## 为什么经典

ResNet 经典，首先是因为它清楚地区分了两个问题：梯度消失/爆炸和 degradation problem。前者是“训练信号能不能传”；后者是“即使能训练，更深模型是否更容易被优化到好解”。ResNet 的贡献在于告诉大家，深度网络的失败不只来自数值不稳定，也来自优化目标的表达方式不友好。

其次，它把“深度”重新打开了。VGG 证明了更深的卷积网络有价值，但 16/19 层已经接近当时普通堆叠路线的实用边界。ResNet 让 50、101、152 层网络成为主流，并在 ILSVRC 2015 分类任务中取得第一名；原论文报告的 residual ensemble 在 ImageNet test set 上达到 3.57% top-5 error。更重要的是，残差网络也支撑了检测、定位、COCO 检测和分割等任务的竞赛结果。

第三，它成了视觉模型的基础骨架。Faster R-CNN、Mask R-CNN、FPN、DeepLab、很多自监督视觉模型，都大量使用 ResNet 或 ResNet-like backbone。很长一段时间里，问一个视觉系统“backbone 是什么”，答案经常就是某个 ResNet 变体。

第四，它让 residual connection 成为深层模型设计里的高频默认项，并与 Transformer 共享了同一类结构思想。Transformer 论文在每个 self-attention 和 feed-forward sub-layer 外都使用 residual connection，并配合 Layer Normalization，形式可以概括为 `x + Sublayer(x)`。从产品视角看，这意味着 ResNet 的价值超出了卷积网络本身：它清楚证明了“复杂模块输出的是对当前表示的增量，而不是完全替换当前表示”可以显著改善深层模型的可训练性。

最后，ResNet 的美感在于取舍很清楚：它没有靠更复杂的模块堆功能，而是用一个低成本结构改变了优化难度。对工程系统来说，这类创新特别重要，因为它提升的是“能力可扩展性”，不是单点指标。

## 产品经理启发

第一，识别问题时要区分“能力不足”和“系统不可优化”。ResNet 面对的不是“卷积层表达力不够”，而是“更深的表达力很难被训练出来”。在 AI 产品里，很多失败也不是模型理论上不会，而是数据、反馈、工具链、权限、评估闭环让能力无法稳定显现。

第二，好的架构应该提供安全默认路径。残差连接让模型在新增层没学好时仍能保留输入信息。产品设计也类似：新增自动化能力、Agent 步骤或多模型链路时，要允许系统在不确定时保持原状态、少改动、可回退，而不是每一步都强制重写结果。

第三，把任务改写成“学习增量”常常比“从零生成答案”更稳。ResNet 让层学习 `H(x) - x`。对应到产品场景，文档改写、代码修复、图像增强、客服建议、数据清洗等任务，如果能表达成“在原内容上做最小必要变更”，通常更容易评估、更容易回滚，也更符合用户心理预期。

第四，复杂系统需要信息高速路。深模型里的 shortcut 类似跨层信息通道；AI 产品里的记忆、上下文摘要、工具调用结果、用户偏好、人工审核意见，也需要稳定地传到后续环节。否则流程越长，信息损耗越大，最后输出看似复杂，实则漂移。

第五，评估不能只看最终榜单，还要看训练误差和失败形态。ResNet 能说服社区，是因为它证明更深 plain network 连训练误差都更差，从而把问题定位到优化难度，而不是泛化差。产品经理做模型评估时也要追问：失败是训练数据不够、模型容量不够、推理策略不对、用户输入分布错，还是评估集定义错？

第六，低成本结构改动可能比堆资源更有价值。残差连接几乎不增加参数，却显著改变可训练深度。产品路线里也要留意这类“杠杆点”：更好的任务拆分、更清晰的状态传递、更合理的人工确认点，可能比简单加模型、加 prompt、加算力更有效。

## 局限与争议

ResNet 不是“越深越好”的保证。原论文展示了 1000 层级别网络可以训练，但也观察到极深网络未必继续带来同等收益。深度增加会带来计算、显存、延迟和部署成本，实际产品里常常要在精度、吞吐、成本之间取舍。

它也不是单独解决深度学习训练的全部方案。ResNet 的成功依赖当时已经成熟的训练组件，例如合理初始化、Batch Normalization、SGD 训练策略和大规模数据集。只拿 `F(x)+x` 这个结构，不能保证任何模型、任何数据规模、任何训练设置都稳定。

原始 ResNet 结构后来也被改进。比如 Identity Mappings in Deep Residual Networks 提出的 pre-activation ResNet，把 BN/ReLU 的位置调整到残差分支前面，进一步改善很深网络的优化。也就是说，ResNet 是关键范式，不是最终形态。

关于“为什么残差有效”，社区有多种解释：有人强调梯度流，有人强调 identity mapping 的预条件化（preconditioning），有人把 ResNet 看成很多浅层路径的集成，也有人从连续动力系统/ODE 角度理解它。这些解释并不完全冲突，但提醒我们不要把一个工程上成功的结构简化成单一原因。

今天在视觉领域，CNN backbone 的中心地位也被 Vision Transformer、ConvNeXt、Swin Transformer、多模态基础模型等路线分散。ResNet 仍然常用，但很多高端系统不再以经典 ResNet 作为唯一默认选择。

## 今天怎么看

今天看 ResNet，最重要的不是记住 152 层或 ILSVRC 名次，而是理解它让深度模型学会了“保留主干、学习增量”。这个思想仍然活在大量现代模型里。

在计算机视觉中，ResNet 仍是强基线和常见 backbone。它结构稳定、实现成熟、迁移学习资源丰富，适合做分类、检测、分割、自监督预训练等任务的基准。即使在 Transformer 流行之后，ResNet 仍常被用于成本敏感、数据量有限、工程稳定性优先的场景。

在 Transformer 中，残差连接几乎是基础设施。Self-attention、MLP/FFN、MoE layer 等模块通常都不是完全替换输入表示，而是在残差通路上添加变换结果。没有这些连接，堆叠几十层、上百层甚至更多层的 Transformer 会更难训练。

在产品判断中，ResNet 代表一种长期有效的架构思想：当系统变深、变长、变复杂时，要设计让信息、梯度、状态和责任能够跨层流动的通道。深度本身不是能力，深度可训练、可调试、可回退，才会变成能力。

需要同时看到的变化是：今天的 AI 产品不一定直接选择 ResNet。若目标是通用视觉理解、多模态检索或图文对齐，CLIP/ViT/SigLIP 等路线可能更相关；若目标是移动端实时视觉，MobileNet、EfficientNet、轻量 Transformer 或端侧专用模型可能更合适。ResNet 的价值更多是作为“深层可训练架构”的经典思想，而不是所有视觉产品的默认答案。

2. 用自己的话解释 `F(x) + x`：其中 `x` 和 `F(x)` 分别承担什么角色？为什么让 `F(x)` 学成 0 比让多层网络学出 identity mapping 更容易？

<details>
<summary>参考要点（先自己答，再展开）</summary>

- `x` 是 shortcut 直接传递的原始输入；`F(x)` 是若干卷积层学习的残差（对输入的修正量）
- 普通网络若要”不改变输入”，需要多层权重和非线性组合恰好等于恒等映射，对优化器来说很难
- 残差块里只要让卷积层输出接近 0，整体就接近 identity；把困难目标（学出 H(x)）改写成更容易的目标（学出 H(x)-x）

</details>

3. 残差连接如何帮助梯度流？请不要只说”防止梯度消失”，而要解释 shortcut 在前向和反向传播中分别提供了什么。

<details>
<summary>参考要点（先自己答，再展开）</summary>

- 前向传播：shortcut 提供一条直达通道，即使残差分支 F(x) 未学好，信息也能通过加法路径传到后层
- 反向传播：梯度不必完全穿过每一层的非线性变换才能传回浅层；加法操作的梯度直接分流到 shortcut 路径，提供更短的梯度通路
- 效果是”安全默认”：模型在新增层没学好时不会破坏已有表示，训练更稳定

</details>

4. ResNet 对 Transformer 的影响体现在哪里？为什么 `x + Sublayer(x)` 对堆叠很多 attention/FFN 层很重要？

<details>
<summary>参考要点（先自己答，再展开）</summary>

- Transformer 中 self-attention 和 FFN 层都使用 `x + Sublayer(x)` 形式的残差连接，配合 Layer Normalization
- 没有这些连接，堆叠几十层 attention/FFN 会遇到与 plain network 类似的优化难度问题
- 残差思想超出了 CNN 范畴，成为深层模型设计的通用结构语言：复杂模块输出的是对当前表示的增量，而不是完全替换

</details>

</details>
